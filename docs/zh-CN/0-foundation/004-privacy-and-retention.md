# 004 — 隐私与数据保留

[English](../../0-foundation/004-privacy-and-retention.md)

TGHarbor 是自托管软件，不提供托管隐私服务。运维者负责合法使用、Telegram 账号权限、文件系统访问、备份、保留、删除及向授权用户披露。

## 持久化数据

- SQLite 保存任务来源标识、请求者 ID、状态/进度/重试、输出路径、原始/当前文件名、MIME 类型、文件大小，以及经过空白规范化且最多 160 个 Unicode 字符的 Telegram 消息摘要。
- 共享目录保存 Inbox/Archive 路径与最近操作者 ID。
- 审计行保存操作者 ID、动作、来源/目标路径和时间。
- 交互会话保存操作者、目标文件、待定名称/目录、步骤和过期时间；不保存回调秘密。
- Telegram 会话文件用于认证 Bot 和用户账号，下载文件属于用户内容；两者都属于敏感数据。

TGHarbor 不会有意持久化完整 Telegram 消息正文或原始 Telegram 对象。当前不实现内容搜索、按内容哈希去重或自动保留删除。

## 访问边界

任务及取消按请求者隔离。所有配置的授权用户均可读取并整理共享文件库。运维者必须据此配置授权列表；TGHarbor 的文件库不是多租户隔离边界。

## 保留与删除

完成任务、目录行、审计、交互、会话和下载文件目前没有自动保留策略。只删除文件或只删除数据库行可能造成不一致。删除或恢复数据时应停止服务并使用经过验证的运维流程。SQLite 数据库和下载根目录必须一起备份和恢复。

公开诊断、仓库、制品或镜像前，必须移除并扫描凭据、会话、消息摘要、私有链接、文件名、数据库内容、日志、下载内容及部署标识，并遵循发布安全指南。
